# RetailPulse - Retail Sales Analytics Project

## 📌 Project Overview

RetailPulse is an end-to-end data analytics project focused on analyzing retail transaction data to uncover sales trends, customer behavior, and business insights.

The project demonstrates a complete analytics workflow:

**Data Collection → Data Cleaning → Data Exploration → SQL Analysis → Data Visualization → Business Recommendations**

---

# 🎯 Business Objective

Retail companies generate large volumes of customer transaction data. The goal of this project is to transform raw sales data into meaningful insights that help answer business questions such as:

- Which markets generate the highest revenue?
- What products contribute the most sales?
- How do sales change over time?
- Who are the most valuable customers?
- How can businesses improve customer retention?

# 📊 Data Analytics Workflow

## 1. Data Cleaning & Preparation

Performed data cleaning using Python:

- Removed duplicate records
- Handled missing values
- Converted data types
- Created calculated fields
- Prepared structured datasets for analysis

---

## 2. Exploratory Data Analysis (EDA)

Analyzed transaction data to identify:

- Revenue patterns
- Customer purchasing behavior
- Product performance
- Market contribution

---

## 3. SQL Analysis

Created SQL queries to answer business questions:

- Monthly revenue analysis
- Top-performing countries
- Customer ranking using window functions
- Revenue-based customer analysis

---

## 4. Customer Segmentation

Performed RFM (Recency, Frequency, Monetary) analysis to identify:

- High-value customers
- Frequent buyers
- Customer purchasing patterns

---

## 5. Data Visualization & Reporting

Built an interactive Power BI dashboard containing:

### Sales Overview
- Total revenue
- Customer metrics
- Market performance

### Trend Analysis
- Monthly revenue trends

### Product Analysis
- Top revenue-generating products

### Customer Analytics
- RFM customer segmentation

---

# 📈 Key Business Insights

- The United Kingdom was identified as the highest revenue-generating market.
- A small group of high-value customers contributed significantly to overall sales.
- Revenue varied across different months, showing purchasing trends.
- Customer segmentation helped identify potential retention opportunities.

---

# 💡 Business Recommendations

Based on the analysis:

- Develop targeted campaigns for high-value customers.
- Improve customer retention strategies using segmentation insights.
- Optimize inventory planning based on product performance.
- Monitor monthly sales trends for better forecasting decisions.
